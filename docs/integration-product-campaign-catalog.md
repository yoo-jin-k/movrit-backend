# 로컬 상품·캠페인 카탈로그 시드

`docs/sql/seed-integration-product-campaign-catalog.sql`은 프론트의 실제 API 연동을 확인하기 위한 로컬 통합 DB 전용 합성 데이터입니다.

- 승인된 테스트 브랜드 `QA ALPHA`, `QA BETA`, `QA GAMMA`에 12개 상품을 분산합니다.
- 프론트가 지원하는 뷰티·식품·생활·패션·디지털 카테고리에 상품을 분산합니다. 스포츠 상품은 지원 카테고리인 생활로 분류합니다.
- 각 상품에 SKU, 가상 프리오더, 모집 중 캠페인, 신청 질문과 필수 동의를 연결합니다.
- 배송형 10개와 방문형 2개를 포함합니다.
- 9개 캠페인은 별도 채널 지표 조건이 없고 3개는 Instagram 팔로워 조건을 사용합니다.
- 상품과 가격은 화면 검수용 가상 값이며 주문·결제·정산 데이터는 생성하지 않습니다.
- 상품명과 SKU를 기준으로 중복을 막아 재실행할 수 있습니다.
- 이미지는 프론트 프로젝트에 포함된 시연용 로컬 배너 자산만 사용하며 외부 상품 사진을 수집하지 않습니다.

적용 후 `GET /api/collaborations/campaigns/open`에서 공개 목록을 확인하고, 각 캠페인의 `/api/campaigns/{id}/application-form`과 로그인 후 `/api/campaigns/{id}/eligibility`를 확인합니다.

공개 목록 응답의 `representativeImageUrl`은 캠페인 대표 이미지 주소입니다. 프론트는 다른 상품 이미지를 추측하지 않고 이 필드만 카드 이미지로 사용해야 합니다.
