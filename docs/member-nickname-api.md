# 회원 닉네임 API 계약

- `name`은 회원 관리용 이름이고 `nickname`은 화면에 표시하는 회원 닉네임입니다.
- 신규 일반 회원가입의 `nickname`은 필수입니다.
- 닉네임은 앞뒤 공백을 제거하고 연속 공백을 하나로 합친 뒤 저장합니다.
- 허용 범위는 2~20자의 한글, 영문, 숫자, 밑줄, 단일 공백이며 전체 회원에서 중복될 수 없습니다.
- `PUT /api/members/me`에서 `nickname`을 보내면 본인 닉네임을 변경합니다. 생략하면 기존 값을 유지합니다.
- `GET /api/members/me`, `GET /api/auth/me`, 로그인·토큰 재발급 응답에 `nickname`이 포함됩니다.
- 기존 회원은 실명을 공개하지 않도록 `user_{memberId}` 형식으로 이관합니다.
- 소셜 신규 가입은 `social_{임의문자}` 임시 닉네임을 발급하며 이후 회원 수정 API에서 변경할 수 있습니다.
