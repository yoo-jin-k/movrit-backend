# MOVRIT 시연 시나리오 (약 10분)

시연 데이터로 캠페인 하나가 신청 → 선정 → 배송 → 콘텐츠 제출 → 승인까지 가는 모습을 역할을 바꿔 가며 보여 줍니다.
중간에 구매평, 방문 예약, 채팅, 신고 처리를 한 번씩 끼워 넣습니다.

## 준비 (1분)

1. 백엔드: `movrit`에서 `scripts/integration.sh start` → http://localhost:18080
2. 프론트: `movrit-frontend`에서 `nvm use && npm run dev:integration` → http://localhost:5174
3. 시연 데이터: `movrit-frontend`에서 `node qa/portfolio/seed-portfolio.mjs` (여러 번 실행해도 결과가 같습니다)
4. 브라우저 창 세 개(일반 창, 시크릿 창, 다른 프로필)에 업체·참여자·운영자를 각각 로그인해 둡니다.

| 역할 | 계정 | 시연 데이터 |
|---|---|---|
| 업체 | `lumi.studio@movrit.local` | 업체 '루미 스튜디오', 브랜드 4개, 캠페인 5개 |
| 참여자 | `haneul@movrit.local` (하늘기록) | 앰플 캠페인 완료, 디너 방문 예약 확정 |
| 참여자 | `minji@movrit.local` (민지데일리) | 앰플 콘텐츠 제출(최종 승인 대기), 원두 구매 인증 |
| 참여자 | `junho@movrit.local` (준호리뷰) | 여러 캠페인에 신청만 해 둔 상태 |
| 운영자 | `demo-admin@movrit.local` | |

비밀번호는 문서에 적지 않습니다. 시연 PC의 별도 보관 파일을 봅니다.

| 캠페인 | 종류 · 받는 방식 | 시연에서 보여 줄 것 |
|---|---|---|
| 시카 수분 앰플 2주 사용 후기 체험단 | 제품 · 배송 | 일정, 송장, 콘텐츠 제출·검토·승인, 평가 |
| 오월 그릴 2인 디너 코스 방문 체험 | 지역(서울) · 방문 | 방문 예약 |
| 콜드브루 원두 구매평 캠페인 | 구매평 · 구매 | 실제 부담 금액, 구매 인증, 환급 |
| 패브릭 미스트 공간 리뷰 체험단 | 제품 · 배송, 채널 클립 | 새 신청 |
| 제주 돌담 독채 1박 숙박 체험 | 지역(제주) · 방문 | 마감 임박 표시 |

## 1. 둘러보기 (1분) · 비로그인

- `/home`: 배너, 카테고리 아이콘, 진행 중인 캠페인. 숙박 체험 카드에 마감 임박 표시
- 원두 구매평 캠페인 상세: 결제 18,900원 · 환급 15,000원 · 실제 부담 3,900원이 같이 보이는 것
- 상단 검색에 '앰플' → 제목·소개·브랜드에서 찾은 결과. 정렬(마감 임박·인기·선정 확률)과 페이지는 서버가 처리합니다
- 찜 버튼을 누르면 로그인으로 안내

## 2. 참여자: 신청 (1분) · minji

1. 패브릭 미스트 캠페인 상세에서 신청서 열기
2. 참여 방식(배송형), 신청 메시지, 수령 정보, 필수 동의 → **신청하기**
3. `/mypage/campaigns`에 '접수'로 들어온 것 확인. 선정 전이라 신청 내용을 고칠 수 있습니다.

## 3. 업체: 선정과 배송 (2분) · lumi.studio

1. `/seller/dashboard`: 선정을 기다리는 신청, 진행 중 참여자, 검토할 콘텐츠 수
2. `/seller/participants` → 패브릭 미스트 캠페인: 준호·민지 두 명을 체크해 **한 번에 선정**
   - 선정하면 바로 참여 확정(진행 중)이 되고, 이때부터 연락처가 보입니다.
3. 참여자 이름 → 상세: 채널 지표, 완료 이력, 활동 등급
4. `/seller/shipping`: 택배사를 고르고 송장번호 입력 → 저장. **배송지 엑셀 내려받기**
5. 참여자 화면(minji)에서 송장번호가 내 캠페인과 알림에 뜬 것 확인

## 4. 참여자: 내 캠페인과 채팅 (2분) · haneul

1. `/mypage/campaigns` → 앰플 캠페인: 일정표, 미션·제출 요건, 송장, 제출한 콘텐츠와 승인 결과
2. 디너 캠페인: 확정된 방문 예약(일시·인원·요청 사항)
3. `/messages`: 브랜드와 주고받은 대화. 사진 첨부, 읽음 표시. 다른 창에서 업체가 입력하면 '입력 중'이 뜹니다.
4. 앰플 캠페인 아래 '콘텐츠 성과': 어제·오늘 조회수·좋아요·댓글과 증감. '오늘 성과 기록'으로 숫자를 고쳐 넣어 봅니다
5. `/mypage`: 활동 등급(완료 1회 · 브론즈)과 다음 등급까지 남은 횟수

## 5. 콘텐츠 검토 → 최종 승인 (1분)

1. 운영자 `/admin/content-reviews`: 민지의 앰플 콘텐츠(업체 검토 완료 · 최종 승인 대기) → **최종 승인**
   - 수정 요청을 고르면 의견이 필수이고, 참여자가 고쳐서 다시 낼 수 있습니다.
2. 업체 참여자 상세: 완료된 참여자에게 별점과 메모 남기기(참여자에게는 보이지 않음)
3. 업체 `/seller/contents` 위쪽 '캠페인 콘텐츠 성과'에서 앰플 캠페인 선택: 게시물 2개의 조회수 합계와 평균 참여율

## 6. 구매평 환급 (1분)

1. 업체 `/seller/paybacks`: 민지의 원두 구매 인증(주문번호·결제 금액·주문 내역 사진) 확인
2. 구매평 승인 후 **환급 완료** 처리 → 참여자 내 캠페인에 환급 완료 표시

## 7. 신고 처리와 운영 도구 (2분) · 운영자

1. `/admin/moderation`: 커뮤니티 광고 댓글 신고 2건(같은 대상)
2. 신고 당시 내용, 작성자, 사유 확인 → **가리기** 또는 **이용 정지**
   - 가리면 같은 대상의 다른 신고도 함께 처리되고, 커뮤니티에는 운영자가 가린 댓글로 표시됩니다.
3. `/admin/community`: 신고 없이도 글·댓글을 바로 가리고 다시 보이게 합니다. 가린 댓글은 회원 화면에 안내 문구로만 남습니다
4. `/admin/reports`: 최근 30일 날짜별 추이 → '직접 고르기'로 기간 바꾸기 → 엑셀 내려받기(요약·날짜별·상태별 시트)
5. `/admin/participation`: 미제출·노쇼·취소 누적 패널티 목록과 취소, 마감 알림 수동 실행, 협의 취소 증빙 확인·승인, 업체 미선정 기록

## 마무리에 짚을 기술 포인트

- 신청 상태 흐름과 역할별 권한(누가 언제 무엇을 바꿀 수 있는지)
- 동시 선정 시 정원 초과 방지(행 잠금), 버전 충돌 409, 신청 내용 스냅샷, 연락처 공개 시점
- 받는 방식(배송·방문·구매)마다 다른 진행 단계
- SSE 채팅, 마감 알림 중복 방지, 라이브러리 없이 만든 엑셀(여러 시트·숫자 칸)
- 서버 검색(조건은 쿼리, 신청 수 정렬은 집계 뒤), 콘텐츠 성과를 (제출 건, 주소, 날짜)로 묶은 이유
- Flyway V1~V18, 자동 생성 ERD, 테스트(백엔드 196 · 프론트 201)와 Playwright 화면 점검
- 자세한 이유: [architecture.md](architecture.md)

## 알려진 제약

- 카카오는 이메일을 주지 않아 계정 자동 병합이 안 됩니다. 계정 설정에서 직접 연결합니다.
- 인스타그램·네이버 연결은 개발자 앱 등록 전이라 꺼 두었습니다. 채널은 직접 등록 후 운영자 확인으로 대신합니다.
- 프리오더·주문·결제는 실제 결제사 연동 없이 상태 흐름만 있습니다.
