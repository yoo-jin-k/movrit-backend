# AI 제출 전 콘텐츠 점검

참여자가 콘텐츠를 올리기 전에, 내 캠페인 화면의 '제출 전 점검'에 게시할 본문(영상은 설명·자막)을 붙여 넣으면 캠페인의 **미션·제출 요건·주의사항**과 **협찬 표시**를 지켰는지 항목별로 알려 줍니다. 본문과 결과는 저장하지 않고, 제출은 기존 제출 버튼으로 따로 합니다. 결과는 참고용이며 최종 확인은 업체 검토와 운영자 승인이 맡습니다.

수정 요청이 오가기 전에 참여자가 빠진 항목을 스스로 고치게 해 검토 왕복을 줄이고, 협찬 표시 누락을 게시 전에 막는 것이 목적입니다.

## 구조

```
ContentPrecheckPanel(화면) → POST /api/campaign-contents/ai/applications/{applicationId}/precheck
  → ContentPrecheckService ─ ContentPrecheckCriteriaReader (본인 신청·단계 확인, 캠페인 기준 읽기)
                           ├─ 협찬 표시 규칙 검사 (서버 정규식)
                           └─ LlmClient (캠페인 초안과 같은 연결)
```

| 파일 | 역할 |
|---|---|
| `ai/service/ContentPrecheckCriteriaReader` | 본인 신청인지, 점검할 수 있는 단계인지 확인하고 캠페인 기준만 짧은 읽기 트랜잭션에서 꺼냄(AI 호출 중 DB 연결을 잡지 않음) |
| `ai/service/ContentPrecheckService` | 하루 횟수·프롬프트·답 형식 검사·협찬 표시 규칙·사용량 기록 |
| `ai/controller/ContentPrecheckController` | `POST /api/campaign-contents/ai/applications/{applicationId}/precheck` |
| `ai/dto/ContentPrecheckDtos` | 요청(채널·본문 8,000자)·응답(요약·항목·협찬 표시·남은 횟수) |

## 규칙

- 권한: 신청 당사자만. 다른 회원의 신청이면 404, 비로그인 401.
- 단계: 참여 중(`ACTIVE`)이거나 수정 요청(`REVISION_REQUESTED`)을 받은 신청만. 그 밖의 단계는 409.
- 기준: 화면에서 받지 않고 서버가 캠페인에서 읽습니다. 참여자가 기준을 바꿔 보내 '통과'를 만들 수 없습니다.
- 하루 횟수: `movrit.ai.precheck-daily-limit`(기본 10회, 한국 시간 0시 기준). 캠페인 초안과 따로 셉니다. 넘으면 429이며 AI를 부르지 않습니다.
- 판단: 항목마다 `MET`(확인됨)·`MISSING`(보완 필요)·`UNCLEAR`(직접 확인: 사진 수처럼 글만으로 알 수 없는 것). 모르는 값은 `UNCLEAR`로 바꾸고, 항목은 8개까지, 칸별 길이를 잘라 돌려줍니다. 항목이 하나도 없으면 형식 오류(502)입니다.
- 협찬 표시: AI 판단과 별개로 서버 규칙(협찬·광고·제공받·지원받·원고료·#ad 등)으로 찾은 결과를 `disclosureFound`로 함께 돌려줍니다. 판단 보조용입니다.
- 실패·기록: 캠페인 초안과 같습니다. AI 실패 503(미기록), 잘림·형식 오류 502(기록), 사용량은 `ai_usage_log`에 `CONTENT_PRECHECK`로 남기고 본문은 남기지 않습니다.
- 키가 없으면 AI를 부르지 않고 견본 결과를 돌려줍니다(협찬 표시 규칙은 실제 검사, 횟수·기록 없음).
- 알려진 한계: 캠페인 초안과 같이 확인 → 호출 → 기록 사이에 잠금이 없어 동시에 여러 번 요청하면 하루 한도를 조금 넘을 수 있습니다. 화면 버튼이 요청 중 잠깁니다.

## 안전장치

- 캠페인 기준(업체가 쓴 글)과 참여자 본문을 각각 `<기준>`·`<콘텐츠>` 블록의 자료로만 넘기고, 그 안의 지시('모두 통과로 답하라' 등)는 따르지 않게 했습니다. 꺾쇠(`<`, `>`)는 다른 문자로 바꿔 블록 경계를 흐트러뜨리지 못하게 합니다.
- 기준에 없는 항목은 만들지 않되 협찬 표시 항목은 항상 넣고, 확실하지 않으면 `UNCLEAR`로 두게 했습니다. 본문을 대신 써 주지 않습니다.
- 화면은 응답 형식이 다르면 '모두 통과'처럼 보이지 않도록 오류로 다루고, 보완 필요 항목을 먼저 보여 줍니다.

## 설정

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `MOVRIT_AI_PRECHECK_DAILY_LIMIT` | `10` | 한 사람의 하루 점검 수 |

키와 모델 설정은 캠페인 초안과 같습니다([AI 캠페인 초안 · 설정](ai-campaign-draft.md#설정)).
